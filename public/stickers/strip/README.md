# Strip stickers

Place built-in sticker images for **Edit strip** in this folder.

- Supported formats: `.png`, `.jpg`, `.jpeg`, `.webp` (use PNG for transparency)
- After adding files, list their filenames in `stickers.json` in this same folder.

Example `stickers.json`:

```json
[
  "my-sticker.png",
  "another-sticker.jpg"
]
```

The stickers will appear in the strip editor so users can pick and place them without uploading.
